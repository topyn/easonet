# Easonet

Independent software reviews for growing businesses.

## Files

- `index.html` — Homepage
- `finder.html` — Software finder quiz
- `CNAME` — Custom domain config for GitHub Pages
- `assets/easonet-logo.svg` — Logo (light backgrounds)
- `assets/easonet-logo-white.svg` — Logo (dark backgrounds)
- `assets/easonet-icon.svg` — Icon mark / favicon
- `assets/images/` — Drop tool images here (800×800px recommended)

## Deploy

1. Push to GitHub
2. Settings → Pages → Deploy from main branch / root
3. Add DNS CNAME record: `www` → `your-github-username.github.io`

## Font

Uses [Syne](https://fonts.google.com/specimen/Syne) (800 weight) + [DM Mono](https://fonts.google.com/specimen/DM+Mono) loaded from Google Fonts.
